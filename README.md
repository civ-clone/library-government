# library-government

A library of `Government`-related objects, each re-exported from the base package that defines it:

- `Governments`: `Anarchy`, `Communism`, `Democracy`, `Despotism`, `Monarchy` and `Republic`.
- `PlayerActions`: `Revolution` (start a revolution) and `ChooseGovernment` (choose the new government once it is
  over).

It registers nothing.
